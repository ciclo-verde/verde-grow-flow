# Ciclo Verde: Cultivating Tomorrow

PROMPT COMPLETO – SITE PROFISSIONAL DA CICLO VERDE

Crie um site completo, moderno, sofisticado, elegante e totalmente responsivo para uma empresa/projeto chamada Ciclo Verde.

A Ciclo Verde tem como objetivo promover sustentabilidade e inovação através da comercialização de hortas sustentáveis e sistemas automatizados de irrigação por gotejamento, que podem ser vendidos separadamente ou em conjunto através de um kit completo.

O site deve ter aparência de uma empresa real, passando credibilidade, confiança, tecnologia, inovação e compromisso ambiental.
